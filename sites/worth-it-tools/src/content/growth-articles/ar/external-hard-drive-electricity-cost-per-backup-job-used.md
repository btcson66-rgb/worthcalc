# تكلفة القرص الخارجي لكل مهمة نسخ احتياطي: احسب النقل والخمول

> **الخلاصة:** عرّف المهمة بالملفات التي نُسخت وتحققت منها فعلياً، وقِس القرص من التوصيل حتى الإزالة الآمنة، ثم اقسم الرسم على المهام المكتملة. إذا بقي القرص مشغلاً بعد النسخ فأدخل زمن الخمول ضمن الحد المعتاد. هذا تقدير للتكلفة وليس ضماناً للتوفير أو الأداء أو السلامة أو الصحة أو الدخل.

## مدخلات تغيّر النتيجة

سجّل نوع القرص وسعته وواجهته والعلبة وحجم البيانات والملفات وخطوة التحقق ودقائق النقل والخمول وkWh المقاسة والتعرفة والتاريخ. افصل الحاسوب والبرنامج إلا عند حساب محطة النسخ كاملة. اختبر نسخة تزايدية صغيرة ونسخة أولى كبيرة. أدخل بدء الدوران والنقل والتحقق والإخراج الآمن؛ النسخة المقطوعة ليست مهمة مكتملة. الملصق يساعد التخطيط، لكن طاقة الحائط المقاسة هي دليل التكلفة.

## الصيغة ومثال مقاس

التكلفة لكل مهمة نسخ مكتملة = kWh المقاسة لحد القرص × التعرفة ÷ المهام التي اكتمل التحقق منها. إذا استهلك النسخ المتحقق منه 0.012 kWh والتعرفة 0.20، فالرسم 0.0024. كرر المهمة بعد الخطأ كساعات عمل إضافية ولا تخفها داخل المتوسط.

## قارن حالات الاستخدام

قارن النسخ التزايدي والكامل والنسخ الذي يتطلب تحققاً طويلاً، واكتب حجم الملفات وتعريف المهمة حتى لا تقارن مزامنة صور بأرشيف كامل بلا سياق. أدلة الاستخدام المقاس ذات الصلة:[كاميرا الويب لكل ساعة اجتماع](/ar/guides/webcam-electricity-cost-per-meeting-hour-used/)、[قاعدة التوصيل لكل يوم عمل](/ar/guides/laptop-docking-station-electricity-cost-per-workday-used/)、[موزع USB لكل جلسة شحن](/ar/guides/usb-charging-hub-electricity-cost-per-charging-session-used/)、[كاميرا المستندات لكل ساعة عرض](/ar/guides/document-camera-electricity-cost-per-presentation-hour-used/) لكل صفحة جهازها ووحدتها المكتملة ونافذة قياسها؛ تشابه kWh لا يجعل النتائج قابلة للتبادل.

## الحدود والأخطاء الشائعة

مؤقت النوم وإدارة USB ومروحة العلبة والكابل وعدد الملفات والتشفير وفحص مضاد الفيروسات والمحاولات تغيّر القراءة. التكلفة المنخفضة لا تثبت أمان البيانات أو جودة النسخة. 先固定費率、設備邊界、開始與結束時間，再做至少三次可重複的實測；若需要比較，保留原始 kWh 與量測日期。

## سؤال شائع

### هل أحسب الحاسوب مع القرص؟

الإجابة: فقط لحساب محطة النسخ الكاملة؛ أما القرص وحده فاعزل العلبة وأظهر طاقة الحاسوب منفصلة.
