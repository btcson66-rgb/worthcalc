# تكلفة موزع شحن USB لكل جلسة: قِس الأجهزة معاً

> **الخلاصة:** قِس الموزع والأجهزة من التوصيل حتى نهاية الشحن المحددة، ثم اقسم الرسم على جلسات مكتملة أو وحدة جهاز معلنة. قراءة الحائط تشمل خسائر التحويل التي لا يظهرها رقم بطارية الهاتف. هذا تقدير للتكلفة وليس ضماناً للتوفير أو الأداء أو السلامة أو الصحة أو الدخل.

## مدخلات تغيّر النتيجة

سجّل المنافذ والمحول والأجهزة وحالة الشحن الابتدائية والنهائية والدقائق ودقائق بلا حمل وkWh المقاسة والتعرفة والتاريخ. اذكر هل الجلسة جهاز واحد يصل للنهاية أم دورة مشتركة لأجهزة عدة. اختبر منفذاً واحداً وكل المنافذ وحالة بلا حمل. أوقف القياس عند النقطة نفسها ولا تعد الجهاز المفصول مبكراً جلسة مكتملة. قارن الشاشة بالعداد ولا تعتبر النسبة عداداً.

## الصيغة ومثال مقاس

التكلفة لكل جلسة محددة = kWh الحائط المقاسة لحد الموزع × التعرفة ÷ وحدات الجلسة المكتملة. إذا استخدمت جلسة جهازين 0.04 kWh وتعرفة 0.20، فالرسم 0.008. يكون 0.004 لكل جهاز أو 0.008 لكل دورة مشتركة حسب المقام المعلن.

## قارن حالات الاستخدام

قارن منفذاً واحداً وكل المنافذ وترك الموزع موصولاً بعد الشحن. أدخل المحول والكابل إذا بقيا متصلين في الاستخدام المعتاد. أدلة الاستخدام المقاس ذات الصلة:[كاميرا الويب لكل ساعة اجتماع](/ar/guides/webcam-electricity-cost-per-meeting-hour-used/)、[قاعدة التوصيل لكل يوم عمل](/ar/guides/laptop-docking-station-electricity-cost-per-workday-used/)、[القرص الخارجي لكل مهمة نسخ](/ar/guides/external-hard-drive-electricity-cost-per-backup-job-used/)、[كاميرا المستندات لكل ساعة عرض](/ar/guides/document-camera-electricity-cost-per-presentation-hour-used/) لكل صفحة جهازها ووحدتها المكتملة ونافذة قياسها؛ تشابه kWh لا يجعل النتائج قابلة للتبادل.

## الحدود والأخطاء الشائعة

حجم البطارية وبروتوكول الشحن وكفاءة المحول والكابل والحرارة والاستخدام الخلفي والشحن التكميلي والاستهلاك بلا حمل تغيّر القياس. الرقم ليس تقييماً لصحة البطارية أو السرعة أو السلامة. 先固定費率、設備邊界、開始與結束時間，再做至少三次可重複的實測；若需要比較，保留原始 kWh 與量測日期。
