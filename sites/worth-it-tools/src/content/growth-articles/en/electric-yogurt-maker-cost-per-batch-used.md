# Electric Yogurt Maker Cost Per Batch Used: Include Incubation Hours

> **Quick answer:** Estimate electric yogurt maker cost per batch by measuring the incubating heater cycle and dividing electricity by the actual finished batch, while keeping milk, starter, and refrigeration separate. Report the electricity boundary clearly. This is a cost estimate, not a guarantee of savings, product performance, food quality, health, or safety.

## Inputs that change the result

The useful denominator is one batch, but the electricity boundary must be chosen first. For this electric yogurt maker, record preheating, incubation, temperature cycling, and any warm-hold period from a defined start point to a defined end point. Keep the starting temperature, load, mode, number of finished units, and any warm-hold or idle time in the same note. A recipe duration or package instruction is not a wall-meter reading.

Start with a repeatable wall-meter test. Record the appliance state before starting, the exact end point, the tariff unit, and the useful output. A nameplate wattage describes a possible load; it does not prove that the heater or motor draws that load continuously. Also save the tariff source and date. A delivered bill rate may include generation, transmission, distribution, taxes, fees, or fixed charges; for an appliance comparison, state whether you used a marginal kWh rate or allocated a fixed charge.

## Formula and worked example

Cost per cycle or session = measured wall kWh from the stated start to the stated end × delivered electricity rate. Cost per batch = that electricity cost ÷ the number of finished batchs. A measured 0.30 kWh incubation at $0.18/kWh costs $0.054 for the batch. If the finished yield is 1.2 kg, that is $0.045 per kg for electricity only; milk, starter, jars, and chilling are not hidden inside that number. This is an illustration of the allocation method, not a prediction for a particular model or household tariff.

Do not multiply the maximum rated watts by the whole recipe or waiting time unless a meter confirms that the device draws that load continuously. Thermostat cycling, motor load, adapter losses, automatic shutoff, and a partly filled tray can all change the measured result.

## Compare real usage scenarios

Run separate measurements for a single large container and several small jars, because warm-up, surface area, room temperature, and the amount poured can alter the cycle. Compare cost per batch with cost per kilogram only after weighing the finished product. Repeat each normal setup at least three times when the load is small, then divide the combined kWh by the number of runs. If the finished output changes, show both the per-batch and per-run denominators. Change one condition at a time and write it down; otherwise a lower number can simply reflect a smaller load, not a different appliance.

## Limits and common mistakes

Results vary with voltage, tariff design, room temperature, moisture, container, cleanliness, control settings, wear, and the meter's resolution. Very short motor runs may not register reliably; a grouped test is more defensible than a single tiny display change. If the question is full ownership cost, list purchase price, ingredients, consumables, refrigeration, maintenance, and time separately instead of hiding them in electricity. Report the electricity boundary clearly. This is a cost estimate, not a guarantee of savings, product performance, food quality, health, or safety.

## Frequently asked question

### Should refrigeration be included?

Include it only when the question is the cost of the complete preparation. For the appliance figure, report incubation electricity separately so the refrigerator does not make the maker look more or less expensive.
