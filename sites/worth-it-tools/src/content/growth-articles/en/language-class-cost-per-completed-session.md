# Language Class Cost Per Completed Session: Count Lessons You Finish

> **Quick answer:** Price a language class by sessions completed, including registration, materials, commute, missed-class fees, and renewal—not sessions merely available.

## Collect the inputs that change the result

Enter tuition, registration, books, platform, transport, rescheduling, missed-class fees, total sessions, sessions completed, and renewal terms.

## Formula and worked example

cost per completed session = (tuition + required materials + transport + fees) ÷ sessions completed. A $300 course plus $40 books and $20 transport has 16 sessions. Completing 12 costs $30 each; completing 6 costs $60 each.

## Use a range instead of a promise

Model full attendance, ordinary absences, and a schedule conflict. Compare group, private, and self-study options by completed practice, not advertised access. Run low-use, realistic-use, and high-use cases. If the result changes, show the range and the assumption that changes it. Do not count a missed class as completed learning. Check make-up rules and renewal dates before treating a monthly plan as flexible.

Keep a short use log for a month or cycle. Separate unavoidable costs from optional extras, record missed uses, and check the current terms before the next charge. This makes the denominator auditable instead of optimistic.
