# 3D scanner electricity cost per scanning session used: separate computer load

> **Quick answer:** Measured scanner, computer, calibration और standby energy से 3D scanner की प्रति scanning session cost निकालें; processing और software costs अलग रखें। यह cost estimate है, savings, product performance, ranking या household outcome की guarantee नहीं है।

## What changes the result

3D scanner cost per scanning session declared wall-meter boundary से शुरू होता है। Start और end को declared wall-meter boundary से तय करें। Device state, load, connected accessories, completed unit, tariff और measurement date लिखें। Rated या typical value test plan में मदद कर सकती है, लेकिन repeatable reading की जगह नहीं लेती।

Session में calibration, repeated passes, preview, file processing और display शामिल हो सकते हैं। Scanner-only या complete workstation boundary स्पष्ट करें।

## Formula and worked example

Electricity cost = measured wall kWh × delivered electricity rate. Unit cost = electricity cost ÷ completed units. Fixed fees, taxes, supplies, repairs, subscriptions और computer/network load को numerator से बाहर रखें जब तक boundary में जानबूझकर शामिल न हों। यदि scanner और measured workstation 0.24 kWh at $0.18/kWh use करते हैं, session cost $0.0432 है। Separate computer 0.11 kWh हो तो totals अलग दिखाएँ।

Wall meter उस load को confirm न करे तो rated wattage को पूरे elapsed period से multiply न करें। Computer, display, network device, charger या accessory हो तो boundary combine करने से पहले उसे अलग measure करें।
