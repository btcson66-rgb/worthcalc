# Bread maker cost per loaf used: kneading और baking energy गिनें

> **संक्षिप्त उत्तर:** Kneading, proofing और baking की measured energy से bread maker cost per loaf निकालें और बिजली, ingredients व समय अलग रखें। Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## परिणाम बदलने वाले inputs

Useful denominator एक loaf, लेकिन पहले electricity boundary तय करें. इस bread maker, record kneading, proofing, baking और keep-warm stage defined start point से defined end point तक। Starting temperature, load, mode, finished units की संख्या और warm-hold या idle time को same note में रखें। Recipe duration या package instruction wall-meter reading नहीं है।

पहले plug-in wall meter से repeatable test करें। Start से पहले appliance state, exact end point, tariff unit और useful output लिखें। Nameplate wattage संभावित load बताता है; यह साबित नहीं करता कि heater या motor पूरे समय उतना ही draw करता है। Tariff का source और date भी save करें। Delivered bill rate में generation, transmission, distribution, taxes, fees या fixed charges शामिल हो सकते हैं; appliance comparison में बताएं कि marginal kWh rate लिया है या fixed charge allocate किया है।

## Formula और worked example

Per cycle या session cost = stated start से end तक measured wall kWh × delivered electricity rate. Per loaf = उस electricity cost ÷ finished loafs. यदि एक cycle 0.42 kWh लेता है और tariff $0.18/kWh है, तो बिजली $0.0756 होगी। आठ हिस्सों में बाँटने पर लगभग $0.00945 प्रति हिस्सा; आटा, yeast और असफल batch अलग हैं। यह allocation method का example है, किसी particular model या household tariff का prediction नहीं।

Meter continuous load confirm न करे तो maximum rated watts को पूरी recipe या waiting time से multiply न करें। Thermostat cycling, motor load, adapter losses, automatic shutoff और partly filled tray measured result बदल सकते हैं।

## वास्तविक उपयोग की तुलना

Dough-only cycle, full bake, छोटा loaf, बड़ा loaf और baking के बाद keep-warm को अलग-अलग मापें। इससे वास्तविक उपयोग-पैटर्न दिखता है, केवल nameplate wattage नहीं। Load छोटा हो तो हर normal setup को कम से कम तीन बार repeat करें और combined kWh को runs की संख्या से divide करें। Finished output बदले तो per-loaf और per-run denominator दोनों दिखाएं. एक समय में एक condition बदलकर लिखें; वरना कम number केवल छोटे load को दिखा सकता है, अलग appliance को नहीं।
