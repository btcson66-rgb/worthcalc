# Cloud storage cost per retained GB: duplicate और unused capacity भी गिनें

> **संक्षिप्त उत्तर:** Cloud plan को retained और genuinely needed data से measure करें, maximum capacity से नहीं; taxes, add-ons, migration और renewal जोड़ें।

## Result बदलने वाले inputs इकट्ठे करें

Price, taxes, family/team add-ons, retained storage, duplicates, migration time, download fees और next renewal price लिखें।

## Formula और worked example

effective cost per retained GB = (subscription + taxes + add-ons + required transfer) ÷ needed retained GB. $12 plan + $2 tax में 140 GB रखा है, पर duplicate हटाने के बाद 80 GB चाहिए; cost $0.175/needed GB है, $0.10 नहीं।

## Promise नहीं, range दिखाएँ

Current, growth और cleanup scenarios compare करें। Delete duplicates, local storage और lower tier के recovery तथा sharing effect देखें। Low-use, realistic-use और high-use cases चलाएँ। Result बदले तो range और बदलने वाली assumption दिखाएँ। Promotional capacity और duplicate files को value न दें। Downgrade से जरूरी recovery या access हटे तो saving नहीं।

एक महीने या cycle का छोटा log रखें। जरूरी cost और optional extras अलग करें, missed uses लिखें और next charge से पहले current terms check करें। इससे denominator optimistic नहीं बल्कि auditable रहेगा।
