# Electric can opener cost per use used: measure motor time, not rated watts

> **संक्षिप्त उत्तर:** Actual cutting के wall-meter reading से electric can opener cost per use निकालें; केवल normal repeated starts को include करें。 Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## परिणाम बदलने वाले inputs

Useful denominator एक use, लेकिन पहले electricity boundary तय करें. इस electric can opener, record motor start, cutting, lid release और unplugging से पहले idle time defined start point से defined end point तक। Starting temperature, load, mode, finished units की संख्या और warm-hold या idle time को same note में रखें। Recipe duration या package instruction wall-meter reading नहीं है।

पहले plug-in wall meter से repeatable test करें। Start से पहले appliance state, exact end point, tariff unit और useful output लिखें। Nameplate wattage संभावित load बताता है; यह साबित नहीं करता कि heater या motor पूरे समय उतना ही draw करता है। Tariff का source और date भी save करें। Delivered bill rate में generation, transmission, distribution, taxes, fees या fixed charges शामिल हो सकते हैं; appliance comparison में बताएं कि marginal kWh rate लिया है या fixed charge allocate किया है।

## Formula और worked example

Per cycle या session cost = stated start से end तक measured wall kWh × delivered electricity rate. Per use = उस electricity cost ÷ finished uses. यदि दस cans मिलकर 0.01 kWh लें और tariff $0.18/kWh हो, group cost $0.0018 और average $0.00018 per use है। Short motor runs meter resolution से छोटे हो सकते हैं; कई uses जोड़कर average लें। यह allocation method का example है, किसी particular model या household tariff का prediction नहीं।

Meter continuous load confirm न करे तो maximum rated watts को पूरी recipe या waiting time से multiply न करें। Thermostat cycling, motor load, adapter losses, automatic shutoff और partly filled tray measured result बदल सकते हैं।

## वास्तविक उपयोग की तुलना

Small load के लिए group test करें और can diameter, lid condition, battery या mains mode तथा jams लिखें। Per-use result तभी comparable है जब start, one lid और endpoint की boundary समान हो। Load छोटा हो तो हर normal setup को कम से कम तीन बार repeat करें और combined kWh को runs की संख्या से divide करें। Finished output बदले तो per-use और per-run denominator दोनों दिखाएं. एक समय में एक condition बदलकर लिखें; वरना कम number केवल छोटे load को दिखा सकता है, अलग appliance को नहीं।
