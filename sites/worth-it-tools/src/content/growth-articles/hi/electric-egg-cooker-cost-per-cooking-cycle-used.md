# Electric egg cooker cost per cooking cycle used: count warm-up and water

> **संक्षिप्त उत्तर:** Selected water level और egg count के लिए measured wall energy से electric egg cooker cycle cost निकालें; maximum rating को cycle consumption न मानें। Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## परिणाम बदलने वाले inputs

Useful denominator एक cooking cycle, लेकिन पहले electricity boundary तय करें. इस electric egg cooker, record water heating, steam cooking और end alert या warm-hold defined start point से defined end point तक। Starting temperature, load, mode, finished units की संख्या और warm-hold या idle time को same note में रखें। Recipe duration या package instruction wall-meter reading नहीं है।

पहले plug-in wall meter से repeatable test करें। Start से पहले appliance state, exact end point, tariff unit और useful output लिखें। Nameplate wattage संभावित load बताता है; यह साबित नहीं करता कि heater या motor पूरे समय उतना ही draw करता है। Tariff का source और date भी save करें। Delivered bill rate में generation, transmission, distribution, taxes, fees या fixed charges शामिल हो सकते हैं; appliance comparison में बताएं कि marginal kWh rate लिया है या fixed charge allocate किया है।

## Formula और worked example

Per cycle या session cost = stated start से end तक measured wall kWh × delivered electricity rate. Per cooking cycle = उस electricity cost ÷ finished cooking cycles. छह अंडों का cycle 0.06 kWh और tariff $0.18/kWh पर $0.0108 होगा, यानी ingredients और water से पहले $0.0018 प्रति egg। चार eggs को अलग मापें क्योंकि water mark और shutoff बदल सकते हैं। यह allocation method का example है, किसी particular model या household tariff का prediction नहीं।

Meter continuous load confirm न करे तो maximum rated watts को पूरी recipe या waiting time से multiply न करें। Thermostat cycling, motor load, adapter losses, automatic shutoff और partly filled tray measured result बदल सकते हैं।

## वास्तविक उपयोग की तुलना

Egg count, starting temperature, water mark और doneness setting लिखें। Per-cycle “इस run की cost” बताता है, जबकि per-egg allocation serving cost बताता है; half-filled tray में दोनों समान नहीं हैं। Load छोटा हो तो हर normal setup को कम से कम तीन बार repeat करें और combined kWh को runs की संख्या से divide करें। Finished output बदले तो per-cooking cycle और per-run denominator दोनों दिखाएं. एक समय में एक condition बदलकर लिखें; वरना कम number केवल छोटे load को दिखा सकता है, अलग appliance को नहीं।
