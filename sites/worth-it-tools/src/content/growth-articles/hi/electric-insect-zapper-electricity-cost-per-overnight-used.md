# Electric insect zapper electricity cost per overnight: standby अलग से मापें

> **निष्कर्ष:** यह measured cost estimate है, product average नहीं और comfort, safety, performance, health या savings का promise नहीं है।

## Result बदलने वाले inputs

Device state, start और stop time, measured kWh, delivered electricity rate और meter boundary लिखें। इस topic के लिए record करें start and stop time, operating mode, light setting, standby minutes, measured kWh, rate और shared outlet devices. एक completed unit को परिभाषित करें **पूरा overnight window** meter reading से पहले। Timer, thermostat, charger, light या standby state हो तो boundary में शामिल है या नहीं लिखें; label में शामिल मानकर न चलें।

## Formula और measured example

Per completed unit = measured kWh × delivered electricity rate ÷ completed units. इस page की unit को बिना explanation के hours, days या cycles में न बदलें। यदि measured window 0.18 kWh और rate 0.20 per kWh हो, cost 0.036 होगा; 3 पूरा overnight window पूरे होने पर 0.012 per unit होगा। यह formula example है, product average नहीं। Raw start और end readings, rate currency और date को result के साथ रखें। Measurement window के बिना rounded number को audit या reproduce करना कठिन है।

## Measurement method

Repeatable reading के लिए same outlet boundary और rate रखें, operating window लिखें और raw meter reading बचाएँ। Plug meter standby और control cycles दिखा सकता है जो label wattage में नहीं दिखते। Similar conditions में window दोहराएँ, लेकिन वास्तविक operating differences को छिपाएँ नहीं। ध्यान दें: start and stop time, operating mode, light setting, standby minutes, measured kWh, rate और shared outlet devices और बताएं कि reading wall meter, plug meter या device display से आई है। Load measured नहीं बल्कि estimated हो तो उसे assumption label दें और total पर उसका असर दिखाएँ।
