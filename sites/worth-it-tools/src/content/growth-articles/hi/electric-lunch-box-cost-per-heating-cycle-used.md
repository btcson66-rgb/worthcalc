# Electric lunch box cost per heating cycle used: separate heat-up and waiting

> **संक्षिप्त उत्तर:** Meal load, warm-up और hold time की measured wall energy से electric lunch box cycle cost निकालें; adapter rating को actual energy न मानें। Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## परिणाम बदलने वाले inputs

Useful denominator एक heating cycle, लेकिन पहले electricity boundary तय करें. इस electric lunch box, record initial warm-up, reheating, thermostat cycling और plugged-in waiting defined start point से defined end point तक। Starting temperature, load, mode, finished units की संख्या और warm-hold या idle time को same note में रखें। Recipe duration या package instruction wall-meter reading नहीं है।

पहले plug-in wall meter से repeatable test करें। Start से पहले appliance state, exact end point, tariff unit और useful output लिखें। Nameplate wattage संभावित load बताता है; यह साबित नहीं करता कि heater या motor पूरे समय उतना ही draw करता है। Tariff का source और date भी save करें। Delivered bill rate में generation, transmission, distribution, taxes, fees या fixed charges शामिल हो सकते हैं; appliance comparison में बताएं कि marginal kWh rate लिया है या fixed charge allocate किया है।

## Formula और worked example

Per cycle या session cost = stated start से end तक measured wall kWh × delivered electricity rate. Per heating cycle = उस electricity cost ÷ finished heating cycles. 45-minute meal cycle में 0.11 kWh और $0.18/kWh tariff हो तो electricity $0.0198 है। Box 30 मिनट और plugged-in रहे तो hold को अलग measure करें, meal में चुपचाप न जोड़ें। यह allocation method का example है, किसी particular model या household tariff का prediction नहीं।

Meter continuous load confirm न करे तो maximum rated watts को पूरी recipe या waiting time से multiply न करें। Thermostat cycling, motor load, adapter losses, automatic shutoff और partly filled tray measured result बदल सकते हैं।

## वास्तविक उपयोग की तुलना

Chilled leftovers, room-temperature food, fill levels और normal power source के साथ repeat करें। USB travel cycle और mains adapter cycle तभी compare करें जब input point और tariff comparable हों। Load छोटा हो तो हर normal setup को कम से कम तीन बार repeat करें और combined kWh को runs की संख्या से divide करें। Finished output बदले तो per-heating cycle और per-run denominator दोनों दिखाएं. एक समय में एक condition बदलकर लिखें; वरना कम number केवल छोटे load को दिखा सकता है, अलग appliance को नहीं।

## सीमाएँ और आम गलतियाँ

Voltage, tariff design, room temperature, moisture, container, cleanliness, control settings, wear और meter resolution से result बदलता है। बहुत short motor runs reliably register नहीं हो सकते; grouped test एक tiny display change से अधिक defensible है। Full ownership cost के लिए purchase price, ingredients, consumables, refrigeration, maintenance और time को electricity में छिपाने के बजाय अलग list करें। Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## अक्सर पूछा गया सवाल

### क्या adapter loss include होनी चाहिए?

Wall meter पर यह naturally included है। Low-voltage side पर measurement हो तो boundary बताएं, क्योंकि adapter loss reading से बाहर है।
