# Electric pressure cooker cost per cooking cycle used

> **संक्षिप्त उत्तर:** Preheat, pressure build, cooking, release और keep-warm की measured wall energy से electric pressure cooker cycle cost निकालें; maximum watts को recipe duration से multiply न करें।

## Result बदलने वाले inputs

Repeatable cold या room-temperature start से meal finish तक measure करें। Pot fill, ingredients, pressure-build minutes, active cooking, natural या quick release, keep-warm, lid changes और served portions record करें।

## Formula और worked example

cost per cycle = start से chosen end तक measured wall kWh × delivered electricity rate. Per portion = cycle electricity ÷ portions served; food, water और prep/cleaning time अलग हैं। Cooker pressure build में 0.08 kWh और cooking, release तथा 20-minute warming में 0.12 kWh लेता है: six-portion pot के लिए 0.20 kWh। $0.20/kWh पर $0.040/pot या करीब $0.0067/portion है।

## Actual use cases compare करें

Half-filled pot, full batch with natural release और two-hour keep-warm recipe compare करें। Load, release और waiting habit बदलने पर per-serving energy बदलती है।

[sandwich-maker use calculation](/hi/guides/sandwich-maker-cost-per-use-used/), [waffle cooking-cycle calculation](/hi/guides/waffle-maker-cost-per-cooking-cycle-used/), [electric-griddle hourly calculation](/hi/guides/electric-griddle-cost-per-cooking-hour-used/) और [stand-mixer session calculation](/hi/guides/stand-mixer-cost-per-mixing-session-used/) से आगे तुलना करें।

## Limits और common mistakes

Load, liquid, starting temperature, programme, release, seal, keep-warm thermostat, voltage और reheating wall reading बदलते हैं। Cost result को guaranteed saving या food-safety advice न बनाएं।

## अक्सर पूछे जाने वाले प्रश्न

### क्या keep-warm time शामिल करें?

यदि घर में खाना परोसने तक cooker warm रहता है तो शामिल करें। Cooking-only और cooking-plus-warming figures अलग दिखाएं ताकि अतिरिक्त समय छिपे नहीं।
