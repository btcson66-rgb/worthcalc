# Wine cooler electricity cost per storage day used: compressor cycling गिनें

> **संक्षिप्त उत्तर:** Measured kWh, compressor cycling, temperature setting और delivered electricity rate से occupied wine-cooler storage day cost निकालें।

## Result बदलने वाले inputs

एक storage day को वही 24-hour window मानें और cabinet full, half-empty या frequently opened है यह लिखें। Repeatable day में wall kWh measure करें; ambient temperature, set point, bottle count, door openings, interior light, display और shared outlet load record करें। Nameplate watts केवल clue हैं, full-day measurement नहीं।

## Formula और measured example

cost per storage day = defined 24-hour window के measured wall kWh × delivered electricity rate. Per-bottle allocation तभी करें जब denominator stored bottles या capacity हो, consumed wine नहीं। अगर cooler 24-hour day में 0.64 kWh record करे और rate $0.22/kWh हो, illustrative cost $0.1408/day है। यह measured scenario है, universal appliance average नहीं। Half-empty और frequently opened cabinet को full और rarely opened cabinet से सीधे compare न करें।

## Real-use windows compare करें

Normal set point पर full cabinet, गर्म सप्ताह में partly empty cabinet और serving के लिए कई बार खुला दिन compare करें। Meter, time window, set-point definition और tariff basis समान रखें। Refrigerator day सिर्फ measurement comparison है; compressor cycling और thermal mass अलग हो सकते हैं।

## Limits और common mistakes

Room temperature, insulation, loading temperature, set point, humidity, door seal, light, display, compressor pauses, voltage और placement reading बदलते हैं। Electricity cost wine quality, safe storage, cooling performance या efficiency साबित नहीं करता। Purchase, repairs, filters और contents value अलग रखें।

## अक्सर पूछे जाने वाले प्रश्न

### क्या bottles की संख्या से divide करें?

Storage-capacity cost पूछ रहे हों तभी। पहले whole-cabinet daily cost दिखाएं, फिर bottle count और allocation बताएं; यह consumption cost नहीं है। Load, set point, room, tariff या opening pattern बदले तो फिर measure करें।
