# Food dehydrator cost per drying hour used: measure heater and fan runtime

> **संक्षिप्त उत्तर:** Wall-meter energy और इस्तेमाल की गई trays से food dehydrator cost per drying hour निकालें; rated wattage को लगातार चलने वाला न मानें。 Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।

## परिणाम बदलने वाले inputs

Useful denominator एक drying hour, लेकिन पहले electricity boundary तय करें. इस food dehydrator, record warm-up, heater cycling, fan circulation और cool-down defined start point से defined end point तक। Starting temperature, load, mode, finished units की संख्या और warm-hold या idle time को same note में रखें। Recipe duration या package instruction wall-meter reading नहीं है।

पहले plug-in wall meter से repeatable test करें। Start से पहले appliance state, exact end point, tariff unit और useful output लिखें। Nameplate wattage संभावित load बताता है; यह साबित नहीं करता कि heater या motor पूरे समय उतना ही draw करता है। Tariff का source और date भी save करें। Delivered bill rate में generation, transmission, distribution, taxes, fees या fixed charges शामिल हो सकते हैं; appliance comparison में बताएं कि marginal kWh rate लिया है या fixed charge allocate किया है।

## Formula और worked example

Per cycle या session cost = stated start से end तक measured wall kWh × delivered electricity rate. Per drying hour = उस electricity cost ÷ finished drying hours. छह घंटे में 1.80 kWh और tariff $0.18/kWh हो तो run cost $0.324, यानी $0.054 प्रति drying hour। आधी trays भरी हों तो load लिखें; इसे full-batch cost न कहें। यह allocation method का example है, किसी particular model या household tariff का prediction नहीं।

Meter continuous load confirm न करे तो maximum rated watts को पूरी recipe या waiting time से multiply न करें। Thermostat cycling, motor load, adapter losses, automatic shutoff और partly filled tray measured result बदल सकते हैं।

## वास्तविक उपयोग की तुलना

Fruit, herbs और dense batches को अलग मापें; moisture, slice thickness, thermostat cycling और tray count runtime और output बदलते हैं। Per-hour metric को per-batch बनाने के लिए अलग denominator चाहिए। Load छोटा हो तो हर normal setup को कम से कम तीन बार repeat करें और combined kWh को runs की संख्या से divide करें। Finished output बदले तो per-drying hour और per-run denominator दोनों दिखाएं. एक समय में एक condition बदलकर लिखें; वरना कम number केवल छोटे load को दिखा सकता है, अलग appliance को नहीं।

Voltage, tariff design, room temperature, moisture, container, cleanliness, control settings, wear और meter resolution से result बदलता है। बहुत short motor runs reliably register नहीं हो सकते; grouped test एक tiny display change से अधिक defensible है। Full ownership cost के लिए purchase price, ingredients, consumables, refrigeration, maintenance और time को electricity में छिपाने के बजाय अलग list करें। Electricity boundary साफ़ लिखें। यह cost estimate है, savings, product performance, food quality, health या safety की guarantee नहीं।
