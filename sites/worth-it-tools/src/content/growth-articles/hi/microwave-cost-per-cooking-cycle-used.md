# Microwave cost per cooking cycle used: wattage, time और failed reheats गिनें

> **संक्षिप्त उत्तर:** Measured input power, active minutes, standby, batch size, electricity tariff, cleanup और usable food से microwave cycle cost निकालें; nameplate wattage cycle cost नहीं है।

## Result बदलने वाले inputs

Input watts, cooking और defrost minutes, session standby, batch size, reheated या discarded food, tariff, delivery charges, cleaning, purchase price और useful cycles record करें।

## Formula और worked example

effective usable-food cycle cost = (active energy + attributable standby + delivery + cleaning and equipment allocation) ÷ useful cycles. Food amount, starting temperature, container और outcome comparable रखें। 1.2 kW microwave 8 minutes चले तो 0.16 kWh लगता है। $0.20/kWh पर direct energy $0.03 है। Cleanup और equipment $0.08 जोड़ें तो useful cycle $0.11 है; एक meal के लिए दो repeat reheats हों तो तीन cycles गिनें।

## Actual use cases compare करें

Refrigerated portion, defrost वाली frozen portion और second round चाहने वाले family batch compare करें। CFPB बताता है कि utility cost local rates और home characteristics से बदलती है; अपने bill या measured tariff का उपयोग करें।

## Limits और common mistakes

Cooking wattage input है, food को मिलने वाली heat नहीं। Container, moisture, load, pause और uneven heating useful output बदलते हैं। Same serving और result के बिना always-cheaper claim न करें।

## अक्सर पूछे जाने वाले प्रश्न

### क्या reheat को अलग cycle गिनें?

हाँ, जब usable food बनाने के लिए अलग run चाहिए। Cycle count और useful servings अलग रखें ताकि batch size और repeat reheating mix न हों।
