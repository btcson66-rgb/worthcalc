# Mobile data cost per GB used: plan minimums को actual usage से compare करें

> **संक्षिप्त उत्तर:** Effective rate में actually used GB, device fee, taxes, overage, throttling और unused rollover शामिल करें।

## Result बदलने वाले inputs इकट्ठे करें

Plan, taxes, device, extra-data fee, hotspot, included GB, used GB, rollover expiry और travel/Wi-Fi months लिखें।

## Formula और worked example

effective cost per GB used = (plan + device + taxes + expected overage) ÷ actual GB used. $55 plan + $10 tax + $5 device, 50 GB included पर 10 GB used: other benefits से पहले $7/used GB।

## Promise नहीं, range दिखाएँ

Low-use, normal-use और travel month compare करें। Coverage और hotspot को unit calculation से अलग रखें। Low-use, realistic-use और high-use cases चलाएँ। Result बदले तो range और बदलने वाली assumption दिखाएँ। Plan justify करने के लिए data use न बढ़ाएं। Unlimited में throttling, hotspot और eligibility terms हो सकते हैं।

एक महीने या cycle का छोटा log रखें। जरूरी cost और optional extras अलग करें, missed uses लिखें और next charge से पहले current terms check करें। इससे denominator optimistic नहीं बल्कि auditable रहेगा।
