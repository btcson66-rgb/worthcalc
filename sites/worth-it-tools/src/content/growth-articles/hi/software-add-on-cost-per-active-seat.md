# Software add-on cost per active seat: feature access और adoption अलग करें

> **संक्षिप्त उत्तर:** Add-on तभी सस्ता per active seat है जब feature use हो; implementation, training, migration, taxes और renewal जोड़ें।

## Result बदलने वाले inputs इकट्ठे करें

Add-on price, taxes, active/paid seats, implementation, training, migration, support, frequency और renewal increase लिखें।

## Formula और worked example

effective cost per active seat = (add-on + implementation + training + support) ÷ active seats using feature. $240 add-on for 12 seats + $120 implementation + $60 training। 6 active पर $70/seat; 12 पर $35।

## Promise नहीं, range दिखाएँ

Half, three-quarter और full adoption scenarios चलाएँ। Feature list नहीं, completed tasks को current workflow से compare करें। Low-use, realistic-use और high-use cases चलाएँ। Result बदले तो range और बदलने वाली assumption दिखाएँ। Unused licensed seats को value न दें। Auto-renewal, seat changes, export और cancellation terms पढ़ें।

एक महीने या cycle का छोटा log रखें। जरूरी cost और optional extras अलग करें, missed uses लिखें और next charge से पहले current terms check करें। इससे denominator optimistic नहीं बल्कि auditable रहेगा।
