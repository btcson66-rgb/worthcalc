# Software seat cost per active user: unused access की लागत देखें

> **संक्षिप्त उत्तर:** Plan, add-ons और admin cost को useful work करने वाले active users से divide करें, purchased seats से नहीं।

## Result बदलने वाले inputs इकट्ठे करें

Plan, seats, add-ons, implementation, admin time, renewal और monthly active users लिखें। Guest और dormant seats अलग रखें।

## Formula और worked example

cost per active user = (plan + add-ons + implementation + admin) ÷ active users. $300 plan + $50 add-on + $100 admin। 8 active users पर $56.25, 3 पर $150/user।

## Promise नहीं, range दिखाएँ

यह utilization audit है, productivity promise नहीं। Normal और low-activity month में completed task मापें। Low-use, realistic-use और high-use cases चलाएँ। Result बदले तो range और बदलने वाली assumption दिखाएँ। Contract या work requirement हो तो seats केवल ratio के लिए न हटाएँ; dormant access को value भी न गिनें।

एक महीने या पूरे उपयोग-चक्र का छोटा log रखें। जरूरी cost और optional add-on अलग लिखें, और planned use न होने का कारण दर्ज करें। इससे denominator वास्तविक व्यवहार पर आधारित रहेगा, optimistic अनुमान पर नहीं।
