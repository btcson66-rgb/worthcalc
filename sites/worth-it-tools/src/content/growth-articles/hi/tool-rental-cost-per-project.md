# Tool rental cost per project: rental days को ownership से compare करें

> **संक्षिप्त उत्तर:** Rental, deposit, delivery, consumables, damage cover और late risk को project days से divide करें।

## Result बदलने वाले inputs इकट्ठे करें

Daily/weekly rent, deposit, delivery, pickup, consumables, coverage, late fees, project days, setup time और buy/borrow cost लिखें।

## Formula और worked example

rental cost per project day = (rental + delivery + consumables + coverage + expected fees) ÷ project days. Two-day rent $45 + delivery $18 + consumables $12। Three-day project $25/day; one-day project $75/day।

## Promise नहीं, range दिखाएँ

One-day, normal और delayed projects test करें। Rental, borrow, used buy और ownership के cash timing तथा storage compare करें। Low-use, realistic-use और high-use cases चलाएँ। Result बदले तो range और बदलने वाली assumption दिखाएँ। Project schedule और deposit को free cash न मानें। Damage, late-return और cancellation terms पढ़ें।

एक महीने या project cycle का छोटा log रखें। जरूरी cost और optional extras अलग करें, missed uses लिखें और next charge से पहले current terms check करें। इससे denominator optimistic नहीं बल्कि auditable रहेगा।
