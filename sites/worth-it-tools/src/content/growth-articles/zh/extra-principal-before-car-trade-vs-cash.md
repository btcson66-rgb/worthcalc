# 準備一年後換車，現在該多繳車貸本金還是留現金？負資產與流動性一起算

## 直接答案

如果你已知道可能在 6～18 個月內換車，額外現金有兩條路：今天多還舊車本金，或保留現金到換車日。多還本金會降低未來 payoff 並減少部分利息，但也立刻降低流動性。核心不是「提前還一定省利息」，而是同時看：

$$
\text{Future Vehicle Equity}
=
\text{Future Net Vehicle Value}-\text{Future Payoff}
$$
以及：

$$
\text{Future Available Cash}
=
\text{Current Cash}-\text{Extra Principal Today}+\text{Future Savings}-\text{Other Uses}
$$
最後在**同一換車日**比較兩條路徑的「車輛淨值＋可用現金」，並確認可用現金沒有跌破你的安全底線。

## 為什麼多還 50,000 不等於「多賺 50,000」？

本金提前還款主要是把 50,000 現金轉成降低 50,000 左右貸款本金，外加避免部分未來利息。你的淨資產不會因這個動作瞬間多 50,000。

因此真正新增的財務價值主要是：

- 未來少付的利息。
- 更早降低負資產風險。
- 換車時更少的 payoff gap。

代價則是：

- 現在可動用現金降低。
- 若之後急需現金，車貸本金通常不能像存款一樣直接拿回。

## Worked Example 1：負資產 50,000，但多還本金後只剩 10,000 自由現金

今天：

- 舊車 payoff：450,000
- 目前可合理賣／trade-in：400,000
- 當前負資產：50,000
- 手上可用現金：180,000
- Protected Cash Floor：120,000

如果今天額外還 50,000：

$$
180,000-50,000=130,000
$$
只剩 10,000 高於安全底線。雖然負資產可快速下降，但家庭現金彈性幾乎被用完。

這不是「提前還不好」，而是說你的 50,000 同時有兩個競爭用途：降低負資產與保護流動性。

## Worked Example 2：把同一筆 60,000 留到換車日

假設距離換車 12 個月，你現在有 60,000 額外現金。建立兩條：

### Path A：今天多還 60,000
- 立即本金下降。
- 之後少付部分利息。
- 換車日 payoff 較低。
- 手上現金少 60,000。

### Path B：60,000 放在專用換車現金帳戶
- payoff 按原貸款下降。
- 仍多付一些利息。
- 換車日可直接用 60,000 補負資產／頭期／稅費。
- 期間仍保持現金可用，但必須避免挪作消費。

比較時不要只看「Path A payoff 少多少」，要算：

$$
\text{Net Position at Trade}
=
\text{Vehicle Value}-\text{Payoff}+\text{Dedicated Cash}
$$
再比較兩條路徑的差，差異主要會來自**利息節省與現金使用限制**，而不是本金本身。

## Payoff Amount 不一定等於帳面本金

CFPB 提醒，汽車貸款的 payoff amount 可能與帳單上看到的 outstanding balance 不同，原因可包含利息或其他費用。換車前要向現有 lender 取得實際 payoff，並確認有效日期。

如果你的貸款有提前清償費、特殊計息或額外付款沒有正確沖本金，模型也要按契約修正。

## Future Car Value 不要用固定折舊率硬估

不要填「車一年一定跌 20%」。距離換車越近，越應使用：

- 同車型目前市場報價。
- 多家 trade-in / buy offer。
- 保守 downside 值。

可以做 3 格：未來車價高／基準／低，看看額外還本金是否只是把你從負資產 -80,000 拉到 -20,000，還是已經轉正。

## 6／12／18 個月 Exit Grid

若換車日期不確定，分別算：

| Exit | 未來 payoff | 未來保守車價 | Equity | Dedicated Cash |
|---|---:|---:|---:|---:|
| 6m |  |  |  |  |
| 12m |  |  |  |  |
| 18m |  |  |  |  |

如果等到 18 個月，不多還也會自然脫離負資產，那保留現金可能更有彈性。若 6 個月必須換且負資產很深，多還本金可能降低下一筆融資壓力，但仍須確保現金底線。

## 不要用新車貸款「藏掉」負資產

007 已處理負資產滾入新貸的成本。若 trade-in 時舊車 payoff 高於價值，差額不是消失，只是可能被加入新的 amount financed，導致新貸更高、利息更多、再次 underwater 的風險升高。

因此本頁的目標，是在換車前 6～18 個月主動管理 equity，而不是等簽新車合約時才處理。

## 結論反轉條件

- 車價比預期跌更快。
- 換車日期提前。
- 發生緊急支出，使現金底線提高。
- 貸款 APR 很低，多還本金節省利息有限。
- 舊貸有特殊提前清償條款。
- 原本 12 個月後換車，改成繼續持有 3 年。

## Decision Matrix

| 條件 | 偏向多還本金 | 偏向留現金 |
|---|---|---|
| 負資產 | 深且短期必須退出 | 很淺或等待可自然改善 |
| 現金 | 多還後仍遠高於 floor | 多還後接近底線 |
| APR | 較高 | 很低 |
| Exit date | 近且明確 | 不確定／可能延後 |
| 自律 | 現金容易被花掉 | 可專款保留 |

## 常見錯算

把多還本金當投資收益；不算流動性；只看今天車價不看換車日；用固定折舊率；不知道實際 payoff；把新車貸款承接負資產當「dealer 幫我付掉」；提前還款後又用信用卡補現金缺口。

## Checklist

- [ ] 向 lender 取得 payoff 與提前還款規則。
- [ ] 取得目前車價至少兩個參考。
- [ ] 設 6／12／18 個月 exit。
- [ ] 分開 Path A 多還本金與 Path B 留現金。
- [ ] 兩條都算換車日 Net Position。
- [ ] 多還後重新檢查 Protected Cash Floor。
- [ ] 車價用 downside 情境再跑一次。
- [ ] 不讓負資產被不透明地滾入新貸。

## 多還本金不等於「省下同樣金額」：先看 payoff 與交易價差

準備換車前把 100,000 拿去多還舊車貸，最直接的效果是降低 payoff，但它不會自動讓舊車市場價上升。若今天 payoff 420,000、實際 trade-in 350,000，你有 70,000 負資產；多還 100,000 後 payoff 約降到 320,000，負資產轉為約 30,000 正權益。這 100,000 主要是在改變交車時需要處理的 equity gap，而不是創造 100,000 收益。

## Cash Floor Test：把同一筆錢留在帳上會發生什麼？

若你有 220,000 現金、保護底線 150,000，拿 100,000 多還本金會讓現金剩 120,000，直接低於底線。即使這讓新車貸更漂亮，也可能把交車後第一個月變得脆弱。請同時顯示兩個方案交車當天的「新貸款起始本金」與「家庭剩餘流動現金」，而不是只比較月付。

## Trade Timing：兩週後換與六個月後換不是同一題

若兩週內確定換車，多還本金主要影響交易結算；若六個月後才換，還要考慮未來六期正常還款、車價變化、額外使用價值與可能維修。不要今天先用一個模糊 trade-in estimate 決定半年後一定多還。可在 Month 0、3、6 重抓 payoff quote 與實際可成交報價，再更新模型。

## 反轉條件：高利率只是其中一個變數

高 APR 讓提前還本金更有利於減少利息，但如果你同時缺乏緊急現金、即將搬家、保費到期或新車頭期需求很高，保留部分現金仍可能更重要。反過來，如果現金遠高於安全底線、舊貸利率高、交易即將發生且負資產會被滾進新貸，多還本金可以降低 rollover。請把「省利息」與「避免把舊債帶進新車」分成兩個效果，不要混成一句「提前還比較省」。

## 最後決策紀錄：把交車日的兩張資產負債表並排

真正簽約前，請列出「多還本金方案」與「保留現金方案」在交車日的四個數字：舊貸 payoff、舊車實際成交價、新車起始貸款、家庭剩餘現金。再加上交車後 30 天一定要付的保費、稅費、停車與第一期貸款。若多還本金讓新貸少 80,000，卻同時讓家庭現金少 100,000 並跌破底線，這個交換就應清楚顯示，而不是只看新月付變低。最後以當天最新 payoff quote 與成交價重算，不使用一個月前的估價。

## 最後校準

如果交易前還要支付保險、牌照、維修或新車訂金，這些都應先從自由現金扣除，再決定可拿多少去提前還本金。不要把同一筆現金同時當成緊急預備金、頭期款與舊貸提前清償資金。

## FAQ

### 多還本金一定能降低負資產嗎？
若額外付款確實沖本金，通常會降低 payoff；但車價也可能同步下降，所以要看兩者相對速度。

### 留現金到換車日跟多還本金不是一樣嗎？
淨本金用途接近，但多還本金會提早節省部分利息並降低貸款餘額；留現金則保留流動性。兩者風險不同。

### 應該先建立緊急預備金還是處理負資產？
沒有單一答案；若多還會讓家庭幾乎沒現金，應把流動性風險納入，而不是只追求 equity 轉正。

### 車商說會幫我清掉舊貸，可以不用管嗎？
仍要看交易文件。若你有負資產，差額可能被加入新貸款。CFPB 建議確認舊貸 payoff 與新合約。

### 低利率車貸還要多還嗎？
若目標是短期降低負資產，仍可能有理由；若純為省利息，低 APR 下節省可能較小，留現金更有價值。

## Sources & Limitations

CFPB 建議換車前確認 payoff amount 與 trade-in value，並說明將負資產滾入新車貸會增加新貸成本。實際提前還款、計息與費用依貸款契約。
