# 租屋押金要準備多少現金？把資金占用、搬家重疊與退還時間放進現金流

## Quick Answer

在台灣，住宅租賃押金金額依法**不得超過兩個月租金總額**。但「準備兩個月押金」仍可能低估搬家現金需求，因為簽約時往往同時出現：

> **新屋簽約現金 = 新押金 + 首期租金 + 仲介／搬家／設定支出 + 可能的租期重疊 − 當下已收到的舊押金退還**

舊押金雖然可能返還，但在真正退回你的帳戶前，它不能同時拿去支付新押金。因此本頁把押金視為**暫時被鎖住的流動性**，不是永久成本。

## 一、台灣押金上限先搞清楚

行政院消費者保護處與租賃住宅相關規定都明確說明：住宅租賃押金不得逾兩個月租金總額；租約消滅、承租人返還住宅並清償租賃債務後，出租人應返還押金或扣抵債務後的剩餘押金。

所以若月租25,000元：

> **法定押金上限 = 25,000 × 2 = 50,000元**

但這不是「搬家只要50,000元」。

## 二、Worked Example：新押金50,000，搬家日現金高峰其實可能110,000

假設：

- 新屋月租25,000；
- 押金2個月：50,000；
- 首月租金：25,000；
- 搬家公司：12,000；
- 新屋簡單設定：8,000；
- 舊屋押金40,000，但退租後才返還；
- 新舊租約重疊15天，舊屋仍需支付12,500元。

搬家前後需要先拿出的現金：

> 50,000 + 25,000 + 12,000 + 8,000 + 12,500 = **107,500元**

如果你只有80,000元現金，雖然「淨成本」可能沒有那麼高，時間點仍然會形成27,500元的流動性缺口。

## 三、押金的關鍵不是利息機會成本，而是「什麼時候回來」

有人會把押金乘上一個假設投資報酬率，說這是押金成本。那是可以做的進階情境，但搬家時更重要的是**現金時序**：

- 新押金在簽約日付；
- 舊押金通常要等返還舊屋、結清費用後才退；
- 兩個日期可能差幾天甚至更久。

建立時間軸：

| 日期 | 事件 | 現金流 |
|---|---|---:|
| 8/1 | 新屋簽約押金 | -50,000 |
| 8/15 | 新屋首月租金 | -25,000 |
| 8/20 | 搬家 | -12,000 |
| 8/31 | 舊屋返還 | 0 |
| 9/5 | 舊押金返還 | +40,000 |

最低現金點通常出現在舊押金回來以前。

## 四、搬家重疊租期不是浪費，可能是風險交換

很多人為了省租金，讓舊租約結束日和新租約起始日完全相同。但如果搬家、清潔、交屋任何一件事延遲，可能造成更高壓力。

重疊7～14天的成本可以直接計算：

> **重疊成本 = 舊租日租金 × 重疊天數 + 新租日租金 × 必要重疊天數（依實際契約）**

它不一定「不划算」，而是用確定的小額成本換搬遷彈性。是否需要由你依家庭、工作與搬運難度決定。

## 五、把舊押金分成「預期可退」與「可立即動用」

資產負債表可以把舊押金視為應收資產，但現金流表不能在尚未退還時把它算成現金。

建議兩欄：

- 應收押金：40,000元；
- 今日可用現金：不含這40,000元。

這個區分能避免「我有12萬元可用」其實其中4萬元還在房東手上的錯算。

## 六、壓力測試：押金只退70%

不是預測房東一定會扣款，而是做風險情境。假設舊押金40,000元，因清潔、損害或未結費用只退28,000元。你的搬家後現金會比基準少12,000元。

請用：

- 100%退還；
- 85%退還；
- 70%退還；

三情境看是否仍能保留必要安全墊。若你已確認沒有欠費或損害，基準可以用100%，但風險欄仍有參考價值。

## 七、租屋押金和緊急預備金不要混成同一筆

新押金是**已知支出／資金占用**，不應在簽約前一天才從緊急預備金拿。若你預計半年後搬家，可以建立：

> **每月搬家基金 =（預估新押金 + 首月租金 + 搬家設定費 − 已另有搬家專款）÷ 剩餘月數**

例如預估需要100,000元、距離搬家5個月：每月沉澱20,000元。

## 八、Decision Matrix

| 情況 | 特別注意 |
|---|---|
| 現金很薄 | 新押金與舊押金退還時間差 |
| 跨縣市搬家 | 交通、住宿、重疊租期 |
| 家庭有幼兒／長者 | 搬家緩衝時間價值較高 |
| 舊屋可能有修繕爭議 | 押金退還金額壓力測試 |
| 新屋需大量家具 | 設定成本不要和押金混在一起 |

## 九、Checklist

- [ ] 新押金沒有超過住宅租賃法定上限
- [ ] 首月租金已另列
- [ ] 搬家與清潔費已估
- [ ] 新舊租約重疊已算
- [ ] 舊押金在未返還前沒有當成現金
- [ ] 有押金只退70%／85%壓力情境
- [ ] 搬家後仍保留必要安全墊
- [ ] 契約已確認押金返還條件

## 十、用「四日期」時間軸找真正最低現金點

押金問題最適合用時間軸，而不是只算總額。至少標記四個日期：**新屋簽約日、新屋起租／搬家日、舊屋返還日、舊押金實際退回日**。然後把每一天的現金流列出來。

例如新屋月租 25,000 元、押金 50,000 元，簽約日同時要付首月租金；搬家與設定費 18,000 元；舊屋押金 40,000 元要等返還住宅、完成點交後才處理。即使你預期舊押金最後全退，簽約到退還之間仍可能先出現：

> **50,000 新押金 + 25,000 首月租金 + 18,000 搬家設定 = 93,000 元現金流出**

如果還有半個月或一個月租期重疊，最低現金點還會更低。這就是為什麼「我舊押金有 40,000，所以新押金只要再補 10,000」是一種危險算法：它忽略了兩筆錢在不同日期才能使用。

### 法規上限不等於你的現金需求上限

內政部目前公布的住宅租賃定型化契約規範，押金不得超過兩個月租金總額；但這只是押金本身的上限，不代表搬家總現金需求只有兩個月租金。首期租金、搬家、仲介或設定支出仍應依實際契約與交易情況逐項列出。租約消滅、承租人返還住宅並清償租賃債務後，押金或扣抵後的剩餘押金才進入返還流程，因此不可把未返還押金當成當日現金。

### 三個退還情境

建議至少做：100% 退回、延後退回、扣除部分費用三種 scenario。不是預測房東一定會扣款，而是確保即使實際退還時間比你預期晚，仍不需要用信用卡循環或短期借款填新屋現金缺口。

## 十一、搬家現金 Checklist

- 新押金依最新契約與法規核對，不只聽口頭說法。
- 把首期租金與押金分開列。
- 不把舊押金在實際入帳前列為可用現金。
- 把搬家、仲介、清潔、家具設定與重疊租期逐項列出。
- 找出時間軸的最低現金點，而不是只算「最後淨成本」。
- 最低現金點仍應保留必要緊急資金，不要把全部預備金投入搬家。


## FAQ

### 台灣租屋押金最多幾個月？
住宅租賃押金不得超過兩個月租金總額。

### 舊押金可以直接拿來算新押金嗎？
只有在你真正收到後才是可動用現金；簽約時若尚未退還，應分開列。

### 押金算成本嗎？
若最終完整退還，它不是永久支出，但在租期內會占用流動性。

### 搬家一定要留重疊租期嗎？
沒有固定答案，可把重疊天數的確定成本和搬家失敗／延遲的風險交換攤開比較。

### 房東扣押金怎麼辦？
本頁不是法律意見。應依租賃契約、實際債務與住宅租賃規定處理，有爭議可使用消保或法律諮詢管道。
