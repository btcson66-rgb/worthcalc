## 通則搞錯的那個比較

「修車不要花超過車子的價值」是這個題目上被轉述最多的規則，而它比較的兩樣東西並不是替代關係。折抵價是你會**收到**的；不修的替代方案是你要**付出**的。兩者差好幾千美元。

有效的比較把兩條路徑放進同一個單位——每個月的交通成本：

    維修路徑 =（維修費 + 預期後續維修）÷ 多出的月數
    換車路徑 =（車價 − 折抵價 + 利息）÷ 持有月數

## 實際算一次

一台需要 2,800 美元變速箱維修的車，未修狀態折抵價 2,100 美元。替代方案是一台 24,000 美元的中古車，利率 8.4%、期數 60 期，打算開五年。

| | 修 | 換 |
| --- | ---: | ---: |
| 現金支出 | 2,800 美元 | 24,000 美元 |
| 收到的折抵 | — | −2,100 美元 |
| 期間總利息 | — | 5,000 美元 |
| 該期間預期的後續維修 | 1,000 美元 | 600 美元 |
| **合計** | **3,800 美元** | **27,500 美元** |
| 買到的月數 | 24 | 60 |
| **每月成本** | **158 美元** | **458 美元** |

再補上比較時通常被丟掉的那幾行。較新的車保費大約每月多 40 美元，較高價值車輛的牌照稅費約多 8 美元：

| | 修 | 換 |
| --- | ---: | ---: |
| 每月成本，基本 | 158 美元 | 458 美元 |
| 多出的保費 | — | +40 美元 |
| 多出的稅費 | — | +8 美元 |
| **每月成本，全部算進去** | **158 美元** | **506 美元** |

以每個月的交通成本來看，修的花費大約是換的三分之一——而這台車按照那條通則應該報廢，因為帳單超過了 2,100 美元的折抵價。

## 維修路徑真正會輸的地方

它只在**買到的月數**那一項上輸，而且只有那一項。其他固定，只動它：

| 維修買到的月數 | 維修的每月成本 |
| ---: | ---: |
| 36 | 106 美元 |
| 24 | 158 美元 |
| 12 | 317 美元 |
| 6 | 633 美元 |
| 3 | 1,267 美元 |

低於大約六個月，維修就不再有競爭力，而這就是真正的決策規則：**一直修，直到維修買不到時間為止。** 一台每四個月就要大修一次的車，不是「貴到不值得修」，而是「它的維修已經買不到任何東西」。

推論是：多出月數的估計就是整個答案，而且它應該取最短的可信值——由**下一個**要壞的東西決定，不是由你現在正在修的那一個決定。

## 什麼條件會讓結論翻轉

- **現有車貸的負權益。** 如果你在一台價值 6,000 美元的車上還欠 9,000 美元，那 3,000 美元的差額會滾進新貸款。它落在換車路徑的分子裡，而且通常在其他因素還沒被考慮之前就決定了比較結果。
- **維修開始群聚。** 一年內兩次重大故障，代表第三次的「多出月數」估計應該取短。訊號是那個模式，不是任何單一張估價單。
- **車子不安全或會拋錨。** 結構件鏽蝕、安全系統失效、會讓你停在高速公路上的故障——這些都不在公式裡，而它們每一項都可能蓋過公式。
- **真的很便宜的替代車。** 上面的比較假設換的是 24,000 美元的車。若換的是 9,000 美元、同利率開四年的車，換車路徑約每月 182 美元，此時買不到 21 個月的維修就不再勝出。
