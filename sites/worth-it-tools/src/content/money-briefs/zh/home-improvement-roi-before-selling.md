## 沒有人真的算過的那筆帳

售前裝修有四個項目，而已發布的「投資報酬率」數字只涵蓋其中兩個：

    淨影響 = 增加的價值 − 工程成本 − 融資成本 − 多出來的持有成本

實例。一間 40,000 美元的廚房，預期回收 60%，用房屋淨值信貸以 9% 借款，從開工到交割共八個月：

| 項目 | 金額 |
| --- | ---: |
| 轉售時增加的價值 | +24,000 美元 |
| 工程成本 | −40,000 美元 |
| 融資：40,000 美元、9%、8 個月 | −2,400 美元 |
| 延遲 2 個月的額外持有成本，每月 2,600 美元 | −5,200 美元 |
| **對售屋淨額的影響** | **−23,600 美元** |

標榜的回收率說你會虧 16,000 美元。融資與延遲把它推到 23,600 美元。這兩項都是真的，都經常被省略，而且工程拖越久它們越糟——而工程正是往拖的方向走。

## 為什麼花越多，回收率越低

彙總數字裡有一個跨市場、跨價格帶都存在的模式：**便宜的工程比昂貴的工程回收得好。** 不是因為昂貴的工程做得差，而是因為兩者買到的東西不同。

| 工程 | 常見花費 | 它改變什麼 |
| --- | ---: | --- |
| 油漆、清空雜物、深度清潔 | 1,500–3,000 美元 | 刊登照片有沒有用 |
| 庭園與大門 | 2,000–5,000 美元 | 買方願不願意下車 |
| 小修繕、五金、照明 | 1,000–4,000 美元 | 房子看起來有沒有被照顧 |
| 浴室改造 | 15,000–30,000 美元 | 一個房間，對上買方品味 |
| 廚房改造 | 30,000–80,000 美元 | 一個房間，對上買方品味 |

前三項改變的是「房子有沒有競爭力」。後兩項改變的是一個房間，而且是按買方沒有參與挑選的規格做的——所以買方不會為一間他們會做成別種樣子的廚房付全額。

## 唯一真的划算的情境

有些房子在賣方能接受的任何價格下都賣不掉，因為某項缺陷讓它落在多數買方能貸款或能投保的範圍之外：驗屋不過的屋頂、無法運作的暖氣系統、不安全的配電盤、正在發生的滲水。修這些不是裝修決策：

    修繕的價值 = 這筆交易能不能成立

那是有上限的成本對上沒有上限的報酬，也是唯一明確值得花錢的類別。判準是這個缺陷會不會**擋住**交易，而不是它能不能讓交易更好看。

## 什麼條件會讓結論翻轉

- **整修過就是市場基準的地區。** 當每一筆可比成交案都有整修過的廚房時，沒整修的那間不是折價，而是失格——這時工程就移到上面「解鎖交易」那一類。
- **你自己動手，而且做得好。** 回收率是對總成本算的，而人工通常佔一半。一間用 18,000 美元材料完成、市值算 40,000 美元的廚房，在這個基礎上回收 133%——但前提是完工品質撐得過估價與驗屋。
- **你還要住很久。** 如果你會再住十年，轉售價值就是錯的判準。正確的問題是「十年更好的廚房你願意付多少」，那是消費問題，而且有完全站得住腳的答案。
- **會改變可比案的結構性變更。** 增加一間合法臥室，或把未完成空間轉為有許可的居住面積，改變的是這間房子的可比案，不是它的裝潢。那是唯一能替房子重新定價、而不只是妝點它的裝修類別。
