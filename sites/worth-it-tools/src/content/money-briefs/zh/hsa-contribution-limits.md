## 2026 年的上限

| | 2026 年 |
| --- | ---: |
| 個人保障 | **4,300 美元** |
| 家庭保障 | **8,550 美元** |
| 追加提撥，55 歲以上 | +1,000 美元 |

適用資格要求投保符合條件的高自付額健康保險，且沒有會取消資格的其他保障。

## 多數比較漏掉的那一段

HSA 通常被描述為「三重稅務優惠」：存入時可扣除、成長時免稅、用於符合資格醫療支出的提領免稅。這是對的，但不完整。

第四個優勢才是有數字的那個。**透過薪資扣繳**的提撥還能避開 7.65% 的薪資稅。401(k) 遞延不行。

    可避稅額（薪資扣繳 HSA）= 提撥額 ×（所得稅率 + 薪資稅率）
    可避稅額（401(k)）      = 提撥額 × 所得稅率

以個人上限提滿、22% 邊際稅率計算：

| 途徑 | 避開的稅率 | 4,300 美元可避稅額 |
| --- | ---: | ---: |
| 薪資扣繳 HSA | 22% + 7.65% = **29.65%** | **1,275 美元** |
| 自行提撥 HSA | 22% | 946 美元 |
| 401(k) 遞延 | 22% | 946 美元 |

同樣的 4,300 美元，走薪資扣繳比其他任何方式多值 329 美元。自行提撥再報稅扣除，就是把這個差額讓出去——這也是為什麼「怎麼提撥」跟「提多少」一樣重要。

## 為什麼它其實不是一個醫療帳戶

讓 HSA 與眾不同的規則，是那些關於「你**沒有**花掉它」時會發生什麼的規則：

- **沒有期限。** 跟 FSA 不同，沒有「用不完就沒收」的日期，餘額無限期往後結轉。
- **可攜。** 它屬於你，不屬於雇主，換工作時跟著走。
- **可以投資。** 多數機構允許把超過現金門檻的餘額投入基金。
- **到達符合資格的年齡後**，非醫療用途的提領是按一般所得課稅，而不是被罰。

綜合起來，一個沒用到的 HSA 表現得像一個退休帳戶——存入時的稅務待遇更好，而用於醫療時連提領都更好。

## 什麼條件會讓結論翻轉

- **底下那張保單。** 稅務優惠是這個決定裡比較小的那個數字。先比較保費差額與最壞情況自付曝險的差額；1,275 美元的稅務減免救不了一張讓你在壞年頭多花 4,000 美元的保單。
- **現金流。** HSA 裡的錢是被綁住的。如果提滿上限意味著醫療帳單最後刷在 24% 的卡上，那就少提一點、保留流動性。
- **你沒注意到的資格問題。** 其他保障——包括某些形式的次要或配偶保障——可能讓你在部分或整年失去資格，而上限會按比例計算。測試標準見 Publication 969。
- **別處的雇主配比。** 退休金配比立即回報 50–100%，仍然排在本頁所有稅率之前。
