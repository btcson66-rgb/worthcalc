## 115 年度的線

| 項目 | 115 年度 |
| --- | ---: |
| 標準扣除額（單身） | **136,000 元** |
| 標準扣除額（有配偶，加倍） | **272,000 元** |
| 每人免稅額 | 101,000 元 |
| 薪資所得特別扣除額 | 227,000 元 |

## 列舉項目與上限（臺北國稅局頁面，標示為 114 年度）

| 列舉項目 | 上限 |
| --- | --- |
| 捐贈 | 一般以不超過綜合所得總額 20% 為限（部分捐贈不受限） |
| 保險費（人身、勞保、國保、就保等） | 每人每年 24,000 元；健保費不受限制 |
| 醫藥及生育費 | 付給公立醫院、健保特約醫院診所等；受保險給付部分不得扣除 |
| 災害損失 | 已受保險賠償或救濟部分不得扣除 |
| 自用住宅購屋借款利息 | 實際利息減除儲蓄投資特別扣除額後的餘額，不超過 30 萬元，以一屋為限 |

## 算式

    可列舉房貸利息 = min(實際支付利息 − 儲蓄投資特別扣除額, 300,000)
    列舉合計 = 捐贈 + 保險費 + 醫藥 + 災損 + 可列舉房貸利息
    列舉多省的稅 = max(0, 列舉合計 − 標準扣除額) × 邊際稅率

## 算例：一對夫妻，有自住房貸

| 項目 | 金額 |
| --- | ---: |
| 房貸利息 200,000 − 存款利息 20,000 | 180,000 |
| 兩人商業保險各 30,000（每人上限 24,000） | 48,000 |
| 全家健保費（不受上限） | 20,000 |
| 醫藥費 | 10,000 |
| **列舉合計** | **258,000** |
| 標準扣除額（有配偶） | 272,000 |

    列舉 − 標準 = 258,000 − 272,000 = −14,000 → 選標準扣除

如果房貸利息是 250,000 元，其他條件不變：

    可列舉房貸利息 = 250,000 − 20,000 = 230,000
    列舉合計 = 230,000 + 48,000 + 20,000 + 10,000 = 308,000
    多出 = 308,000 − 272,000 = 36,000
    12% 級距可多省 = 36,000 × 12% = 4,320 元

## 什麼條件會讓結論翻轉

- **存款利息越多，房貸利息扣得越少。** 儲蓄投資特別扣除額要從房貸利息中先減掉，存款多的家庭反而比較難靠房貸列舉贏過標準扣除。
- **單身。** 單身的線只有 13.6 萬元，一筆較大的房貸利息就可能超過，而有配偶的線是 27.2 萬元。
- **邊際稅率。** 同樣多出 36,000 元，在 5% 級距只省 1,800 元，在 30% 級距省 10,800 元。
- **大額醫療或捐贈的年份。** 去年選標準扣除，不代表今年也是；醫療支出或捐贈特別多的那一年，要用當年的單據重新加總比較。
