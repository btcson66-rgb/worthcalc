## 為什麼一般的比較方式是錯的

到處看得到的建議是：把買斷價跟車子的價值比，車子比較值錢就買。那只是半個計算。它替資產定了價，卻忽略了替代方案，而替代方案——還車——並不是免費的。

    買斷優勢 = 市價 + 避掉的費用 −（殘值 + 手續費 + 稅 + 規費）

## 算式

實例——租約到期，殘值 19,500 美元，車子市價 21,200 美元，駕駛超出里程額度 6,000 英里。

**買斷的成本：**

| 項目 | 金額 |
| --- | ---: |
| 殘值（買斷價） | 19,500 美元 |
| 買斷手續費 | 350 美元 |
| 銷售稅 7% | 1,365 美元 |
| 過戶與牌照 | 180 美元 |
| **買斷總成本** | **21,395 美元** |

對上 21,200 美元的市價，等於虧 195 美元——照一般的比較方式，你會把車還回去。

**還車的成本：**

| 項目 | 金額 |
| --- | ---: |
| 處分費（disposition fee） | 395 美元 |
| 超里程 6,000 英里 × 0.25 美元 | 1,500 美元 |
| **因買斷而避掉的費用合計** | **1,895 美元** |

**兩邊一起看：**

    21,200 + 1,895 − 21,395 = +1,700

買斷多賺 1,700 美元。兩次計算之間，車子本身沒有任何改變；第二次只是把「被拿來比較的那個選項」也算了進去。

## 把里程這件事講白

超里程費存在的目的，是替你已經造成的折舊定價。如果你把車還回去，你用現金支付那筆折舊。如果你把車留下來，你擁有的就是那筆折舊——而你早就在買斷價裡付過了，那個價格是好幾年前訂的，不會因為你的里程而調整。

這就是為什麼超出里程額度是支持買斷最有力的論點，也是為什麼最容易被說服還車的人，往往正是該留下車的那一個。

## 什麼條件會讓結論翻轉

- **車子價值低於殘值。** 那麼殘值保證正在對你有利，還車才對。那個數字是出租方好幾年前訂的，訂太高的風險由他們承擔。
- **你所在州的稅務處理。** 有些州已經透過月付收過稅，有些對全額買斷價課稅，有些只對殘值課稅。7% 這個假設可能在任一方向上差好幾百美元。
- **你沒超里程、而且車況良好。** 那麼避掉的費用只剩處分費，決定就回到單純的價差。
- **買斷的融資利率。** 如果你付不出現金，買斷貸款的利率就是成本的一部分。在較差的信用等級下，融資 19,500 美元產生的利息可能超過那 1,700 美元的優勢。
