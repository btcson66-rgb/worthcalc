## 算式

寵物保單是「事後核退」而不是直接給付，而且在核退之前要先扣兩層：

    理賠金額   =（可理賠帳單 − 年度自付額）× 理賠比例
    打平帳單   = 年度自付額 +（年保費 ÷ 理賠比例）

實例——一組常見的報價結構：月繳 55 美元、年度自付額 250 美元、理賠比例 80%、年度上限 5,000 美元。

| 輸入值 | 數值 |
| --- | ---: |
| 年保費 | 660 美元 |
| 年度自付額 | 250 美元 |
| 理賠比例 | 80% |
| **打平可理賠帳單** | **1,075 美元** |

驗算：（1,075 − 250）× 0.80 = 660，恰好等於保費。

把它攤開到不同年份看：

| 可理賠獸醫帳單 | 理賠金額 | 保費 | 淨值 |
| ---: | ---: | ---: | ---: |
| 0 | 0 | 660 美元 | **−660 美元** |
| 600 美元 | 280 美元 | 660 美元 | **−380 美元** |
| 1,075 美元 | 660 美元 | 660 美元 | 0 |
| 3,000 美元 | 2,200 美元 | 660 美元 | **+1,540 美元** |
| 9,000 美元 | 3,800 美元（受 5,000 上限限制） | 660 美元 | **+3,140 美元** |

注意最後一列。在年度上限 5,000 美元之下，一場 9,000 美元的急症，扣掉自付額與比例後核退 3,800 美元——不是 9,000，也不是 7,000。上限正好在你買這張保單所為的那一年發揮作用。

## 打平點告訴你什麼

一隻健康動物的例行年份——一次健檢、疫苗、一個小毛病——達不到 1,075 美元的**可理賠**帳單，而例行照護通常本來就被排除。所以多數年份的預期結果就是虧損，這是設計如此。所有保險都是這樣。

因此問題不是「這平均會不會划算」——不會——而是**「沒有它，我扛不扛得住壞的那一年？」** 如果一場 9,000 美元的急症會刷在 24% 的信用卡上，這張保單買到的是真的東西。如果你有現金，那你是在付錢請保險公司替你保管它，同時換回一個上限。

## 除外條款比數字更能決定結果

有三件事推翻算式的頻率高於保費：

1. **既往症。** 幾乎每張保單都排除。即使是投保後才確診的病症，只要被認定與先前病歷上的徵兆有關，仍可能被排除。這是理賠遭拒最大的單一來源，也代表替「已經有症狀的動物」投保，很少能達到買方預期的效果。
2. **年度與單一病症上限。** 如上表所示，上限在災難情境下咬得最兇。請拿它去對照你害怕的那項處置的實際價格，而不是平均值。
3. **隨年齡重新定價。** 保費會隨動物年齡上升。你在牠兩歲時用來算打平的那個報價，不是牠九歲、也就是真的會理賠時你要付的保費。

## 什麼條件會讓結論翻轉

- **品種或年齡帶有已知、昂貴、可保的風險。** 當五位數處置的機率明顯高於平均，而該病症尚未出現時，期望值會往保單那一邊移動。
- **沒有現金緩衝。** 保險與存款是用不同方式解決同一個問題；如果那筆存款不存在，那麼兩者之中只有保單是實際拿得到的。
- **上限高於你最壞的合理情境。** 沒有上限或年度上限很高的保單，會徹底改變上表的最後一列，而且在保費相近時，價值明顯高於上限 5,000 美元的那種。
