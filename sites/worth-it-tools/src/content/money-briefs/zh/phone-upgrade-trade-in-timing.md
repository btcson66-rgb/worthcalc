## 這個方案實際上是什麼

「舊機折抵最高 1,000 美元」幾乎從來不是折 1,000 美元。它的意思是：在你維持為符合資格資費的客戶期間，每月從帳單折抵 27.78 美元，連續 36 個月。

    實得折抵 = 每月折抵 × 你留下的月數

| 你留下的月數 | 實得折抵 | 放棄的金額 |
| ---: | ---: | ---: |
| 36 | 1,000 美元 | 0 |
| 30 | 833 美元 | 167 美元 |
| 24 | 667 美元 | 333 美元 |
| 18 | 500 美元 | 500 美元 |
| 12 | 333 美元 | 667 美元 |

這個方案不是手機的折扣，是「留下來」的折扣，只是被以手機折扣的方式定價與宣傳。本頁其餘一切都由此推導出來。

## 換機的完整成本

    實質成本 = 新機價格 − 實得折抵 + 舊機未付餘額

以「在前一份 24 個月合約的第 18 個月換機」計算：

| 項目 | 金額 |
| --- | ---: |
| 新機價格 | 1,100 美元 |
| 舊機折抵，牌面 | −1,000 美元 |
| 下次換家之前 22 個月實際收到的折抵 | −611 美元 |
| 舊機未付餘額 | +220 美元 |
| **實質成本** | **709 美元** |

對照牌面算術 1,100 − 1,000 = 100 美元，真實數字是它的七倍。造成落差的兩行都不算隱藏——合約裡都寫了——但兩行都不在那個方案廣告裡。

## 決定結果的比較

把電信商方案與直接賣掉並列，兩邊都誠實估值：

| | 電信商折抵 | 私下賣出 |
| --- | ---: | ---: |
| 牌面價值 | 1,000 美元 | 600 美元 |
| 支付方式 | 分 36 個月 | 立即 |
| 是否以留下為條件 | 是 | 否 |
| 依你真實在網時長的預期實得 | 611 美元 | 600 美元 |
| 是否綁定資費層級 | 是 | 否 |
| **可比價值** | **611 美元** | **600 美元** |

以三年在網時長來看，電信商方案輕鬆勝出；以十八個月來看，它輸給一個牌面上少 40% 的私下賣價。決定變數不是方案本身，而是你會留多久——那是關於你的事實，不是關於手機的。

## 什麼條件會讓結論翻轉

- **你真的不會換家。** 在同一家待了十年的人會把折抵全部收滿，那這個方案的價值就接近它的牌面。放棄風險是真的，但它不是普遍的。
- **分 24 個月而不是 36 個月的折抵。** 期間越短，你收到的比例越高，方案也越接近它宣稱的樣子。比較兩個方案時，比「折抵期長度」通常比比「折抵金額」更有資訊量。
- **舊機已經付清。** 拿掉餘額那一項就是拿掉最大的單一減項，而把換機時間點抓在合約結束而不是中途，光憑這一點就實質便宜很多。
- **手機真的在壞。** 如果它撐不完一個工作天，或已經停止接收資安更新，那上面的算式就不是正在被問的問題。換掉它是功能性決策，折抵結構只決定你怎麼付錢。
