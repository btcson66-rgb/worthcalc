## 這個決定不是在賭機率

多數說法把它當成一個期望值賭局：出事機率低、免責保險很貴，所以拒買。這個推理不完整，因為你拒買之後要承擔的東西，完全取決於「改由什麼來賠」。

    拒買的成本 = 損壞機率 ×（自付額 + 加費總額 + 停駛損失與各項費用）

三種備援狀態，會得出三個差距極大的數字。

## 三種狀態

**主位保障。** 一張會先行理賠、不動用你自己保險的卡。理賠完全不花你的錢，也不會在你的車險紀錄上留下痕跡。

| | |
| --- | ---: |
| 免責保險價格，7 天 × 32 美元 | 224 美元 |
| 拒買後的曝險 | 約 0 |

拒買顯然正確。免責保險賣給你的，是你早就有的東西。

**次位保障。** 卡片只賠你自己的保險沒賠的部分——所以理賠要先走你的個人保單。

| 項目 | 金額 |
| --- | ---: |
| 你的車損自付額 | 1,000 美元 |
| 保費加費，每年 460 美元 × 3 年 | 1,380 美元 |
| **每一次損壞事故的曝險** | **2,380 美元** |

若單次租車的損壞機率為 3%，期望成本約 71 美元，對上 224 美元的免責保險——平均而言拒買仍然勝出。但你現在是為了省 224 美元而扛著一條 2,380 美元的尾端風險，而卡片的「保障」賠的是「真正傷到你的那部分之後」的東西。

**完全沒有保障。** 沒有個人車險，也沒有卡片權益。曝險是全額修理費加上停駛損失，此時買下免責保險通常是對的。

## 櫃檯不會告訴你的事

有三筆費用落在多數人對「車損」的想像之外：

- **停駛損失（loss of use）**——車輛維修期間租車公司損失的營收，有時按整段維修期以日租金計費。
- **價值減損（diminished value）**——車輛轉售價值下跌的請求金額。
- **行政費用**——處理理賠的固定費用。

免責保險通常把這三項一併解決。卡片保障與個人保單賠不賠這些各有不同，而它們正是租車理賠中最常起爭議的部分。

## 什麼條件會讓結論翻轉

- **你沒查的某一條除外條款。** 常見的三項是車種、國家與租期長度。一項排除廂型車、或超過 15 天租期、或你所在國家的卡片權益，在那趟行程上的價值是零。
- **沒有個人車險。** 次位保障後面若什麼都沒有，可能什麼都不賠。這是沒有自用車的人最常見的破口。
- **長租期。** 免責保險的費用隨天數增加，而曝險不會，所以租 30 天、一天 32 美元就是 960 美元，對上同樣的 2,380 美元尾端風險。長租期即使在較弱的狀態下也會把答案推向拒買。
- **一趟出爭議就毀掉的行程。** 如果為了一份修理估價吵兩週會毀掉這趟旅程或它所為的工作，那麼買下免責保險是在買確定性。就這樣稱呼它，不要假裝那是划算的保險。
