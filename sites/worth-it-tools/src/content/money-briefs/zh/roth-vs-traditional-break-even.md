## 正確陳述這個比較

    傳統型稅後價值 = 提撥額 ×(1 + r)^n ×(1 − 將來稅率)
    Roth 稅後價值  = 提撥額 ×(1 + r)^n

乘法可以交換，所以「一開始課稅」和「最後課稅」在**稅率相同時**會得到同樣的結果。這就是標準答案的全部，而且它是對的：

| | 傳統型 | Roth |
| --- | --- | --- |
| 將來稅率**低於**現在 | **勝** | |
| 將來稅率**高於**現在 | | **勝** |
| 稅率相同 | 平手 | 平手 |

人們爭論的其他一切，都是在預測你幾十年後的所得，而且是在會改變的稅法之下。這也是為什麼決勝點很重要。

## 決勝點：上限是一個名目數字

2026 年的員工提撥上限是 24,500 美元，兩種都一樣。但 24,500 美元的傳統型與 24,500 美元的 Roth，花掉你的「實際的錢」並不一樣多。

以 22% 邊際稅率計算：

| | 提撥額 | 實領薪資的代價 | 被庇護的 |
| --- | ---: | ---: | ---: |
| 傳統型 | 24,500 美元 | **19,110 美元** | 24,500 美元（稅前） |
| Roth | 24,500 美元 | **24,500 美元** | 24,500 美元（稅後） |

提到上限的傳統型提撥，把 19,110 美元的「你的錢」搬進庇護裡；提到上限的 Roth 提撥搬進 24,500 美元。在同樣的名目上限下，那是**多 28% 的你自己的錢**。

這只有在你真的提到上限時才會起作用。還沒到上限時，你可以靠多提傳統型來拉平，平手就回來了。

## 數字長什麼樣

提撥 24,500 美元、20 年、7% 報酬、以 22% 稅率提領：

| | 傳統型 | Roth |
| --- | ---: | ---: |
| 20 年後價值 | 94,808 美元 | 94,808 美元 |
| 提領時的稅 | −20,858 美元 | 0 |
| **稅後** | **73,950 美元** | **94,808 美元** |
| 今天的實領代價 | 19,110 美元 | 24,500 美元 |

Roth 最後高 28%，而當初也多花 28%。在稅率相同時那是打平——正如公式所說。不對稱只有在「上限擋住你多提」時才出現。

## 實務排序

1. **先拿滿雇主配比**，不管計畫把它放進哪種帳戶。立即 50–100% 的報酬凌駕整個問題。
2. **職涯early、低稅級** → Roth。你的稅率之後不太可能更低，現在用低稅率繳掉很便宜。
3. **收入高峰、高稅級** → 通常傳統型勝，因為扣除的價值恰好在你稅率最高時最大。
4. **兩種都會提滿** → 上限的不對稱偏向 Roth。
5. **真的不確定** → 各放一半。同時持有讓你退休後每年可以選擇從哪邊提領，而那份彈性本身就有價值。

## 什麼條件會讓結論翻轉

- **預期稅率大幅下降。** 今天 32%、將來以 12% 提領的人應該拿扣除，沒有任何上限不對稱補得起 20 個百分點的差距。
- **州稅。** 從高稅州搬到沒有所得稅的州退休，會讓扣除比單看聯邦比較更有價值。
- **強制提領。** 傳統型餘額受最低提領額規定約束，可能逼出你不需要的所得；Roth 餘額在歷史上的處理方式不同。那是規劃上的差異，不是稅率上的差異。
- **會變的規則。** 高所得者的提撥與追加提撥處理方式已多次修訂。在決定多年期計畫之前，請先確認當下的規定。
