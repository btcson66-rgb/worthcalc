## 兩個時薪，只有一個是真的

一份副業對它的主人宣稱的時薪，是毛收入除以計費時數。從那個數字到真正進帳戶的錢之間，每一項扣減都是看不見的，而自僱收入的扣減項特別多。

    真實時薪 =（毛收入 − 成本 − 自僱稅 − 所得稅）÷（計費 + 未計費時數）

## 算式

實例——副業收入 9,000 美元、計費 300 小時，營業成本 1,200 美元，一年 40 小時用於報價、開發票與記帳。

| 項目 | 金額 |
| --- | ---: |
| 毛收入 | 9,000 美元 |
| 減：營業成本 | −1,200 美元 |
| **淨利** | **7,800 美元** |
| 減：自僱稅（7,800 × 0.9235 × 0.153） | −1,102 美元 |
| 減：所得稅，7,249 美元（淨利減一半自僱稅）× 22% | −1,595 美元 |
| **實際留下** | **5,103 美元** |

| 分母 | 時數 | 時薪 |
| --- | ---: | ---: |
| 只算計費時數 | 300 | 帳面 30.00 美元 |
| 這份工作佔用的所有時數 | 340 | **真實 15.01 美元** |

帳面時薪恰好是真實時薪的兩倍。過程中沒有發生任何異常：數字都很普通，而「砍半」是結構性的。

## 每一塊錢去了哪裡

原本的 9,000 美元中：

- **1,200 美元**是成本——執行這份工作的真實支出。
- **1,102 美元**是自僱稅——薪資稅的兩半，因為你同時是雇主也是受僱者。
- **1,595 美元**是所得稅。
- **5,103 美元**留下來。

自僱稅那一行是最讓人意外的，也是「30 美元的承攬費率」與「30 美元的受僱時薪」不是同一份工作的原因。受僱者的 7.65% 有雇主對等負擔；承攬者則是自己一個人付淨利 92.35% 的 15.3%。

## 未計費時數

在 300 小時的年度裡，40 小時的行政聽起來很寬鬆。對多數副業來說，那其實是樂觀的。報價、催款、記帳、採購、工作之間的移動，以及找下一個客戶的時間，全都由這份工作造成，而且沒有一項會被計費。

那些時間是純粹的分母：它降低時薪，卻不降低稅。它同時也是多數人最快的槓桿，因為砍掉十小時未計費時間，對真實時薪的提升大於漲價 3%。

## 什麼條件會讓結論翻轉

- **受僱而非承攬身分。** 透過薪資支付的工作，有一半薪資稅是別人付的，光這一項就值毛收入的約 7.65%。
- **你沒申報的真實可扣除費用。** 按當期 IRS 費率計算的里程、符合資格的家庭辦公室扣除、設備與軟體，都會降低淨利，因而同時降低兩種稅。沒申報的扣除額，是這裡最常見的非受迫失誤。
- **較低的邊際稅率。** 本頁使用的 22% 是一個假設。稅級較低的家庭留下的明顯更多，而超過社會安全稅薪資上限之後，12.4% 那一段就消失了。
- **本質上不是按時計價的工作。** 如果副業在累積一項資產——受眾、產品、口碑——時薪會低估它，因為有一部分報酬是後來才到來的，根本不在今年的收入裡。
