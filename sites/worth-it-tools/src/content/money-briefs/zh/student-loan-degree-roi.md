## 沒有人開帳單的那筆成本

學費與貸款都附帶文件。比較大的那筆成本沒有。

實例——四年學業，以 6.52% 借 27,000 美元、十年還清，對照本來每年可以賺到的 35,000 美元：

| 組成 | 金額 | 佔比 |
| --- | ---: | ---: |
| 貸款還款總額 | 42,824 美元 | 23% |
| 放棄的收入，4 × 35,000 美元 | **140,000 美元** | **77%** |
| **總投資** | **182,824 美元** | |

大家吵的那筆債務不到成本的四分之一。沒有人開帳單的那四分之三，是時間。

## 回本

    回本年數 = 總投資 ÷ 年薪溢價

| 年薪溢價 | 畢業後回本 |
| ---: | ---: |
| 15,000 美元 | 12.2 年 |
| **25,000 美元** | **7.3 年** |
| 40,000 美元 | 4.6 年 |
| 8,000 美元 | 22.9 年 |

表上每一列都是同一個學位、同樣的債務。變動的是溢價——而溢價是**領域**的性質，不是文憑的性質。

## 為什麼中位數是錯的數字

公布的「依教育程度分類的收入」是非常大的母體的中位數。它們是真的，但對一個個人決定來說是錯的解析度，因為背後的分布寬到足以讓同一張資格在某個領域是極佳投資、在另一個領域是差勁投資。

請用你找得到最窄的資料：領域，以及有公布的話，學校。全國中位數告訴你的是一個母體發生了什麼事，不是你身上可能會發生什麼事。

## 真正能撼動它的兩個槓桿

**減少放棄的收入。** 這是最大的一項，所以也最敏感。就學期間年賺 15,000 美元，會把這一行從 140,000 美元降到 80,000 美元——總投資下降 33%，沒有任何學費折扣追得上。

**唸完。** 沒唸完是會讓整個計算倒過來的情境：債務與放棄的收入都發生了，而大部分溢價沒有。把溢價乘上一個實際的完成機率，是誠實版本的這個算式所做的最重要的一項修正。

## 什麼條件會讓結論翻轉

- **需要執照的專業。** 當這紙資格是執業的法定要件時，替代方案不是比較低的薪水——而是這份工作不存在。回本計算並不描述那個選擇。
- **雇主出錢。** 由雇主支付學費、邊工作邊在職進修，會同時移除兩個大項，算式也就不再接近。
- **溢價很小的領域。** 溢價 8,000 美元時回本要 23 年，對多數人而言那根本不構成投資理由，不論這個學位還有什麼其他價值。
- **金錢量不到的一切。** 失業率隨教育程度下降，而穩定性有本頁沒有定價的價值。
